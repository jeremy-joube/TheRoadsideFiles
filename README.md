# THE ROADSIDE FILES

## &#x1f1fa;&#x1f1f8;

> "Some stories are too strange to be forgotten."

« The Roadside Files » is a fictional archive dedicated to collecting reports,
witness testimonies, disappearances and unexplained events occurring across
the United States.

Most of these files are probably hoaxes.

Probably.

---

## What is this project?

« The Roadside Files » is a personal web project for a "Monster of the Week" role-playing game inspired by:

- Supernatural
- Buffy the Vampire Slayer
- The X-Files
- Early 2000s internet forums
- Urban legends and cryptids
- Small-town America

The website is designed as an in-universe archive where visitors can browse:

- Cryptid sightings
- Strange disappearances
- Witness reports
- Local legends
- Community investigations
